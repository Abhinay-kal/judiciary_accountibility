## Complete API Reference

### Health Check
```bash
curl http://localhost:8000/api/v1/delay-detection/health
# Returns: { status, phases available, baseline metrics }
```

### Get Baseline
```bash
curl "http://localhost:8000/api/v1/delay-detection/baseline?recalculate=false"
# Returns: Population statistics from resolved cases
```

### Analyze Single Case [PRIMARY]
```bash
curl http://localhost:8000/api/v1/delay-detection/case/42
# Returns: {
#   probability: 82.5,
#   risk_level: "high",
#   confidence: 0.87,
#   explanation: "Case exhibits high probability...",
#   primary_drivers: ["High bench hunting (z=2.8)"],
#   anomalies: ["bench_hunting_z: 2.8", "party_score_z: 2.1"]
# }
```

### Batch Analyze
```bash
curl -X POST "http://localhost:8000/api/v1/delay-detection/batch?case_ids=1,2,3,4,5"
# Returns: {
#   total_cases_analyzed: 5,
#   success_count: 5,
#   error_count: 0,
#   results: [ {case_id, probability, risk_level, ...} ],
#   summary_stats: { mean, min, max, median, stdev }
# }
```

### Get Case Features
```bash
curl http://localhost:8000/api/v1/delay-detection/case/42/features
# Returns: { adjournment_density, party_driven_score, dormancy_cv, bench_hunting_index }
```

### Get Z-Scores
```bash
curl http://localhost:8000/api/v1/delay-detection/case/42/z-scores
# Returns: { density_z, party_score_z, dormancy_cv_z, bench_hunting_z, composite_z, anomalies }
```

## Questions & Support

### Common Questions
**Q: How do I analyze one case?**  
A: `GET /api/v1/delay-detection/case/{case_id}` returns probability, risk_level, and explanation

**Q: Can I analyze multiple cases at once?**  
A: Yes! `POST /api/v1/delay-detection/batch?case_ids=1,2,3,...` analyzes 1-1000 cases with aggregate stats

**Q: What's the probability range?**  
A: 0-100, where 75-100 is "extreme" risk, 50-75 is "high", etc.

**Q: How often should I recalculate the baseline?**  
A: Weekly or after disposing many cases. Use `?recalculate=true`

**Q: What if a case has no hearings?**  
A: The API returns a valid response with low confidence = 0.3
